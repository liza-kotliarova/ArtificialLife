# Artificial Life

Лабораторная работа по объектно-ориентированному программированию на Java.

## Описание проекта

Проект моделирует искусственную экосистему, состоящую из растений, травоядных и хищников.

В процессе симуляции агенты перемещаются по полю, взаимодействуют друг с другом и окружающей средой, получают и теряют энергию, питаются и размножаются.

Симуляция выполняется пошагово, а состояние экосистемы отображается в графическом интерфейсе.

## Основные сущности

В модели используются следующие типы объектов:

- **Plant (Растение)** — растёт и размножается.
- **Herbivore (Травоядное)** — перемещается по полю, питается растениями, теряет энергию и размножается.
- **Predator (Хищник)** — перемещается по полю, охотится на травоядных, теряет энергию и размножается.
- **Environment (Окружающая среда)** — хранит игровое поле и управляет взаимодействием агентов.
- **Agent (Агент)** — базовый класс для объектов экосистемы.

## Возможности программы

- моделирование экосистемы на двумерном поле;
- перемещение агентов;
- поиск пищи;
- питание растений травоядными;
- охота хищников на травоядных;
- получение и потеря энергии;
- размножение агентов;
- гибель агентов при недостатке энергии;
- пошаговое выполнение симуляции;
- автоматический запуск и приостановка симуляции;
- изменение скорости выполнения;
- отображение текущего количества растений, травоядных и хищников.

## Графический интерфейс

Для визуализации используется графический интерфейс Java Swing.

На поле отображаются:

- 🌱 растения;
- 🐇 травоядные;
- 🐺 хищники.

Интерфейс позволяет запускать и приостанавливать симуляцию, выполнять отдельные шаги и изменять скорость моделирования.
